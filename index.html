ABOUT THIS PROJECT

Aperture

A lightweight browser-style dashboard for ChromeOS.

How Aperture works

Aperture is a regular website. Its internal tabs switch between Aperture pages and tools. When you visit an external website, Aperture opens it in a regular Chrome tab so the site can use its normal browser features.

Some sites block being displayed inside another website. A normal hosted website cannot override that restriction or become a replacement browser engine.

Privacy

Your bookmarks, theme and notes are stored locally in this browser using local storage. Aperture does not run a server or collect your browsing history.
